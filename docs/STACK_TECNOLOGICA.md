# Stack Tecnológica — TechOS

- **Frontend:** HTML5, CSS3, JavaScript
- **Backend:** Node.js + Express (com `mysql2`, `jsonwebtoken`, `bcryptjs`, `dotenv`, `cors`)
- **Banco de Dados:** MySQL (XAMPP / MySQL Workbench)
- **Justificativa:** O Node.js com Event Loop assíncrono atende aos requisitos de desempenho (RNF01) e integra nativamente com JSON e o frontend em JavaScript.
